**Описание алгоритма:**\
1.Вычисляется среднее из 4-х значений

2.Те значения, которые отличаются от среднего более, чем на D=20%
переводятся в разряд кандидатов на удаление. Значения, являющиеся
кандидатами на удаление, но отличающиеся от хотя бы одного из остальных
3-х значений на величину меньшую, чем d=10% от среднего, не удаляются из
рассмотрения. Остальные кандидаты на удаление удаляются из
рассмотрения.(Если из рассмотрения оказались удаленными все 4 исходных
значения, то задают D=D+10% и заново переходят к выполнению пункта 2).

3. Из оставшихся значений находят среднее и считают его средним
значением интенсивности флуоресценции четырех ячеек для данного
аллергена.

 

Предлагаемый алгоритм не позволит отбросить из рассмотрения как большую,
так и меньшую компоненту дублетов близких значений.

 

Значения  D  и  d  будут скорректированы разработчиками опытным путем.

**Пример:**\
**Исходные данные:**\
x₁ = 446.8601, x₂ = 473.3045, x₃ = 508.8601, x₄ = 501.5268

**Параметры:**\
D = 20% (порог для кандидатов на удаление)\
d = 10% (порог для \"спасения\" кандидата)

**Шаг 1: Вычисление первоначального среднего**

Находим среднее арифметическое всех четырех значений.\
Среднее = (x₁ + x₂ + x₃ + x₄) / 4\
Среднее = (446.8601 + 473.3045 + 508.8601 + 501.5268) / 4\
Среднее = 1930.5515 / 4\
Среднее = 482.637875

**Результат шага 1:** Среднее₀ = 482.64 (округляем для удобства, но в
расчетах используем полное значение)

**Шаг 2: Определение кандидатов на удаление**

Вычисляем 20% и 10% от среднего.\
20% от среднего (D) = 482.637875 \* 0.20 = 96.527575\
10% от среднего (d) = 482.637875 \* 0.10 = 48.2637875

Теперь находим абсолютное отклонение каждого значения от среднего и
проверяем, превышает ли оно D=96.53.

1.  **x₁ = 446.8601**

    - \|446.8601 - 482.637875\| = **35.777775**

    - 35.78 \< 96.53 → **НЕ кандидат на удаление**

2.  **x₂ = 473.3045**

    - \|473.3045 - 482.637875\| = **9.333375**

    - 9.33 \< 96.53 → **НЕ кандидат на удаление**

3.  **x₃ = 508.8601**

    - \|508.8601 - 482.637875\| = **26.222225**

    - 26.22 \< 96.53 → **НЕ кандидат на удаление**

4.  **x₄ = 501.5268**

    - \|501.5268 - 482.637875\| = **18.888925**

    - 18.89 \< 96.53 → **НЕ кандидат на удаление**

**Результат шага 2:** Ни одно из значений не отличается от среднего
более чем на 20%. Кандидатов на удаление нет.

**Шаг 3: Финальный расчет**

Поскольку кандидатов на удаление не было, мы просто заново вычисляем
среднее арифметическое из всех четырех исходных значений. Оно у нас уже
вычислено на Шаге 1.

**Итоговый результат:** Средняя интенсивность флуоресценции = 482.64
